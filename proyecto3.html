El Proyecto

Este proyecto es un sistema para llevar control de las piezas que se fabrican en la empresa Fabricados López.

Antes todo se apuntaba en papel, lo que hacía difícil encontrar información. Ahora tenemos un programa en Python que guarda todo de forma ordenada.

Que resuelve?

  • Ya no hay que buscar entre papeles
  • Todo está en un solo sitio
  • Se sabe quién fabricó cada pieza y cuándo
  • Es fácil ver si una pieza está bien o defectuosa

Como Funciona

Es un programa de consola muy simple en Python. Tiene tres funciones principales:

Funciones:

  • Añadir pieza: Se introducen los datos (ID, operario, fecha, tipo, estado)
  • Ver todas las piezas: Muestra una lista completa
  • Buscar por ID: Busca una pieza concreta por su código

Tecnología:

  • Python (lenguaje de programación)
  • CSV (archivos para guardar datos)
  • HTML y CSS (esta página web)

# Resumen

En este repositorio se recoge la solución global a los distintos retos asociados a cada uno de los puestos de trabajo de la empresa, dentro de un contexto de transformación digital e industria 4.0.

## Javier – Responsable de Sistemas  
Javier dispone de una base de datos en la que se han definido todas las entidades, atributos, relaciones y cardinalidades del sistema. Además, se han establecido los principales objetivos tecnológicos orientados a una industria 4.0. Esta base de datos la podrás ver en la carpeta "html" y es el archivo "proyecto.html", para ejecutarlo puedes copiar el código en visual y arrastras el archivo a una pestaña del navegador.

## Pablo – Supervisor de Producción  
Pablo trabaja con la base de datos diseñada por Javier, junto con varios programas desarrollados en Python que permiten llevar un registro detallado de las piezas de cada vehículo. Asimismo, se utiliza otra base de datos gestionada mediante **SQLite3**, accesible desde la nube. Esta base de datos sobre sqlite la puedes encontrar en la carpeta "python" y es el archivo "sqlite.py", para ejecutarlo puedes copiar el código en visual y poner en la terminal de visual el comando "py squlite.py" este comando se utiliza en Windows, si tienes Linux tendrás que escribir el comando "python sqlite.py".

## Lucía – Ingeniera de Procesos  
Lucía cuenta con diferentes animaciones que representan los procesos productivos. En la animación seleccionada se pueden visualizar claramente los componentes que se van incorporando durante el proceso de fabricación. Esta animación la puedes encontrar en la carpeta "html" y es el archivo "animacion.html".

## Mari Carmen – Directora de Recursos Humanos  
Mari Carmen dispone de un juego interactivo en **Kahoot** con preguntas relacionadas con contratos de trabajo, Seguridad Social, relaciones laborales y el Estatuto de los Trabajadores. Este Kahoot lo puedes encontrar en la carpeta "html" y es el archivo "proyecto.html" para ejecutarlo puedes copiar el código en visual y arrastras el archivo a una pestaña del navegador. También puedes encontrar estas preguntas en un archivo de python, que está en la carpeta "python" y es el archivo "juegoempleabilidad.py", para ejecutarlo puedes copiar el código en visual y poner en la terminal de visual el comando "py juegoempleabilidad.py" este comando se utiliza en Windows, si tienes Linux tendrás que escribir el comando "python juegoempleabilidad.py".

## Ohian – Responsable de Digitalización y Sostenibilidad  
Ohian gestiona información clave sobre la computación en la nube, la ciberdelincuencia y el Big Data, enfocada a la mejora de la digitalización y la sostenibilidad empresarial. Esta información la puedes encontrar en la carpeta "html" y es el archivo "proyecto.html", para ejecutarlo puedes copiar el código en visual y arrastras el archivo a una pestaña del navegador. 

## Alain – Responsable Comercial  
Alain cuenta con un podcast que resume el reto del proyecto y una sección de preguntas frecuentes (FAQ) que recogen las dudas más habituales de los clientes. Esta información la puedes encontrar en la carpeta "html" y es el archivo "proyecto.html", para ejecutarlo puedes copiar el código en visual y arrastras el archivo a una pestaña del navegador.

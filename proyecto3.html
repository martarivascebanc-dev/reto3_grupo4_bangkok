El Proyecto

Este proyecto es un sistema para llevar control de las piezas que se fabrican en la empresa Fabricados López.

Antes todo se apuntaba en papel, lo que hacía difícil encontrar información. Ahora tenemos un programa en Python que guarda todo de forma ordenada.

Que resuelve?

  • Ya no hay que buscar entre papeles
  • Todo está en un solo sitio
  • Se sabe quién fabricó cada pieza y cuándo
  • Es fácil ver si una pieza está bien o defectuosa

Como Funciona

Es un programa de consola muy simple en Python. Tiene tres funciones principales:

Funciones:

  • Añadir pieza: Se introducen los datos (ID, operario, fecha, tipo, estado)
  • Ver todas las piezas: Muestra una lista completa
  • Buscar por ID: Busca una pieza concreta por su código

Tecnología:

  • Python (lenguaje de programación)
  • CSV (archivos para guardar datos)
  • HTML y CSS (esta página web)

El paso del papel a lo digital

Mediante este proyecto lo que buscamos es sustituir el uso de papel por herramientas digitales.

¿En que se basa el sistema?

  • El sistema se basa en una arquitectura Edge-Fog-Cloud Donde se introducen en los equipos del taller, se procesan en un servidor local y se alamacenan en la nube facilitando el acceso y el control de la información.
  • Mejoras: Centralizar datos, mejorar el seguimiento de la producción y reducir errores.

Tecnología al servicio del planeta

El proyecto de Fabricados López integra la sostenibilidad de forma transversal, alineandose con los Objetivos Desarrollo Sostenible de la Agenda 2030.

Ventajas de la prodducción responsable

  • Reducción del impacto ambiental: Disminucion del uso de papel, reducción de residuos, menor consumo de recursos y optimización de los procesos productivos gracias a la digitalización.
  • Mejora social y organizativa: Mejor organización del trabajo, mayor transparencia, desarrollo de competencias digitales y mejora de trazabilidad y control de la información.

Nuestro modelo de entidad relacion

Es una base de datos diseñada que permite organizar y gestionar la información de nuestra fábrica de automóviles de forma estructurada.

Modelo:

  • Entidades: Cada una de ellas cuenta con una clave principal que la identifica y con claves foraneas que permiten relacionarla con las demás.
  • Estructura: El modelo sigue una estructura relacional con relaciones principalmente de 1:N, lo que evita duplicar información y garantiza la integridad de los datos.
  • Conclucion: Esta base de datos permite realizar un seguimiento completo del proceso productivo, facilitando la trazabilidad de cada coche, el control del montaje, la gestión personal y la supervisión de la calidad.

🏆 Concurso de Animaciones

Como parte de nuestro proyecto, participamos en un concurso de animaciones web donde cada miembro del equipo tenía que desarrollar una propuesta creativa que representara algún aspecto de la industria manufacturera.

🎨 Nuestra Propuesta Ganadora

Tras evaluar todas las propuestas del equipo, seleccionamos la animación del Proceso de Fabricación de Coches como nuestra entrada al concurso.

¿Por qué elegimos esta animación?

  • Representación visual clara: La animación muestra de forma sencilla y visual el proceso de ensamblaje de un vehículo, algo que cualquier persona puede entender de inmediato.
  • Interactividad: A diferencia de una animación pasiva, esta permite al usuario participar activamente en el proceso de fabricación mediante botones interactivos, lo que hace la experiencia más educativa y entretenida.
  • Conexión con nuestro proyecto: Se alinea perfectamente con el objetivo principal de Fabricados López, que es la trazabilidad y control de piezas en procesos industriales. Cada paso de la animación representa una fase del proceso productivo que necesita ser registrada y controlada.
  • Simplicidad técnica y elegancia: La animación utiliza CSS y JavaScript de forma eficiente, demostrando que no hace falta complicar demasiado las cosas para crear algo efectivo y atractivo.
  • Valor educativo: Sirve como herramienta didáctica para explicar conceptos de manufactura secuencial y ensamblaje por etapas, algo fundamental en la industria automotriz.

El autor

Esta animación fue desarrollada por uno de los integrantes de nuestro equipo, quien demostró creatividad y habilidades técnicas al combinar HTML, CSS y JavaScript para crear una experiencia visual interactiva que representa fielmente los valores de nuestra empresa.

La animación ha sido muy bien recibida por su capacidad de transmitir conceptos complejos de fabricación de una manera accesible y visual, además de reflejar el espíritu innovador y tecnológico de Fabricados López.

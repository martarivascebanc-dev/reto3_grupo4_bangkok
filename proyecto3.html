Descripción del Proyecto

Esta página web complementa el proyecto de **control y trazabilidad de piezas**. Permite a los usuarios entender cómo funciona el sistema, la importancia de registrar cada pieza correctamente y conocer datos generales sobre la empresa Fabricados López.

El objetivo principal es asegurar la calidad, facilitar la gestión de producción y preparar la base para futuras mejoras como la implementación de una base de datos real.
